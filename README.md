# 📺 My Live Streaming App

A simple Android Live Streaming Application built using **Kotlin** and **ZEGOCLOUD UIKit**.  
Users can:

- 🎥 Start a Live Stream as Host
- 👥 Join Live Stream as Audience
- 🔊 Real-time Audio & Video Streaming
- ⚡ Fast Integration using ZEGOCLOUD Prebuilt UIKit

---

# 📱 Features

- Host Live Streaming
- Audience Joining
- Real-time Video Communication
- Random User ID Generation
- Simple and Clean UI
- ZEGOCLOUD UIKit Integration

---

# 🛠️ Tech Stack

- Kotlin
- Android Studio
- ZEGOCLOUD UIKit
- XML Layouts
